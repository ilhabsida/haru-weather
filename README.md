# 하루정리

계산기와 실시간 날씨, 할 일 목록, 메모, 집중 타이머를 담은 작은 생산성 앱입니다.

**웹사이트: https://ilhabsida.github.io/haru-weather/**

## 사용하기

웹사이트에 접속하거나 `index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드 과정이 없습니다.

- 서울·부산·인천·대구·대전·광주·제주 날씨
- 키보드 입력을 지원하는 계산기 (입력 순서대로 계산)
- 할 일 목록과 완료율
- 25분 집중 / 5분·15분 휴식 타이머
- 자동 저장 메모
- 모바일 화면 지원

## 데이터와 개인정보

날씨는 [Open-Meteo](https://open-meteo.com/)의 API를 사용하며 인터넷 연결이 필요합니다. 표시되는 날씨는 선택한 도시 기준입니다.

할 일과 메모는 사용하는 브라우저의 로컬 저장소에만 저장됩니다. 서버나 GitHub로 전송되지 않으며 기기 간 동기화되지 않습니다. 브라우저 데이터를 삭제하면 저장된 내용도 삭제됩니다.

## 배포

GitHub Pages에서 `main` 브랜치의 루트 폴더(`/`)를 배포합니다. `index.html` 변경 사항을 커밋하고 푸시하면 자동으로 반영됩니다.
