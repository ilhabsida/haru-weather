# 하루정리 🌿

**날씨를 확인하고, 할 일을 정리하고, 잠깐 집중할 수 있는 나만의 작은 작업실입니다.**

계산기, 날씨, 할 일 목록, 집중 타이머, 메모를 한 화면에 담았습니다. 회원가입이나 별도 프로그램 설치 없이 PC와 모바일 브라우저에서 사용할 수 있습니다.

## 바로 사용하기

### 👉 [하루정리 열기](https://ilhabsida.github.io/haru-weather/)

위 링크를 누르면 앱이 열립니다. 자주 사용한다면 브라우저 즐겨찾기에 추가해 두세요.

> 이 GitHub 페이지는 앱을 소개하고 소스 코드를 보관하는 곳입니다. 실제 앱은 위의 **하루정리 열기** 링크에서 사용할 수 있습니다.

## 어떤 기능이 있나요?

| 기능 | 할 수 있는 일 |
| --- | --- |
| ☀️ 오늘의 날씨 | 선택한 도시의 기온, 체감온도, 습도, 풍속 확인 |
| 🧮 가벼운 계산 | 사칙연산, 소수점, 부호 변경, 백분율 계산 |
| ✅ 오늘 할 일 | 할 일 추가·완료·삭제 및 완료율 확인 |
| ⏱️ 집중 타이머 | 25분 집중, 5분 또는 15분 휴식 |
| ✏️ 빠른 메모 | 떠오른 생각을 적고 브라우저에 자동 저장 |
| 🕒 날짜와 시계 | 현재 기기의 날짜와 시간 확인 |

## 기능별 사용법

### 1. 오늘의 날씨

1. 날씨 카드 오른쪽 위에서 도시를 선택합니다.
2. 기온과 날씨 상태, 체감온도, 습도, 바람 정보를 확인합니다.
3. 최신 정보가 필요하면 **새로고침 ↻**을 누릅니다.

- 선택 가능한 지역: **서울, 부산, 인천, 대구, 대전, 광주, 제주**
- 내 위치를 자동으로 추적하지 않고, **선택한 도시**를 기준으로 보여줍니다.
- 날씨는 [Open-Meteo](https://open-meteo.com/)에서 제공하며, 인터넷 연결이 필요합니다.
- 정보를 불러오지 못하면 안내 메시지가 나타납니다. 연결을 확인하고 다시 시도해 주세요.

### 2. 가벼운 계산

화면의 숫자·연산 버튼을 누르거나 키보드로 입력하면 됩니다.

| 버튼 / 키 | 의미 |
| --- | --- |
| `+`, `−`, `×`, `÷` | 더하기, 빼기, 곱하기, 나누기 |
| `=` / `Enter` | 계산 결과 확인 |
| `AC` / `Esc` | 계산 전체 초기화 |
| `+/−` | 양수와 음수 전환 |
| `%` | 현재 숫자를 100으로 나누기. 예: `50` → `0.5` |
| `Backspace` | 입력 중인 숫자를 한 자리 지우기 |

키보드에서는 곱하기에 `*`, 나누기에 `/`를 사용하세요. 할 일이나 메모를 작성하는 동안에는 계산기 단축키가 작동하지 않습니다.

> **계산은 입력 순서대로 진행합니다.** `2 + 3 × 4 =`를 입력하면 `(2 + 3) × 4`로 계산하여 `20`이 나옵니다. 수학식의 곱셈 우선순위를 적용하는 계산기는 아닙니다.

### 3. 오늘 할 일

1. 입력 칸에 할 일을 적고 **+** 버튼 또는 `Enter`를 누릅니다.
2. 끝낸 일은 왼쪽 체크박스를 선택합니다. 위쪽에 완료 개수와 완료율이 표시됩니다.
3. 개별 항목은 오른쪽 **×**로 삭제합니다.
4. **완료한 일 지우기**를 누르면 체크한 항목만 한 번에 삭제됩니다.

할 일은 자동 저장됩니다. 날짜가 바뀌어도 자동으로 초기화되지 않으므로, 필요에 따라 직접 정리해 주세요.

### 4. 집중 타이머

1. **집중 25분**, **휴식 5분**, **휴식 15분** 중 하나를 선택합니다.
2. **▶**를 누르면 시작하고, **Ⅱ**를 누르면 일시정지합니다.
3. **↺**를 누르면 선택한 시간으로 초기화합니다. 다른 모드를 선택해도 초기화됩니다.
4. 시간이 끝나면 앱 화면에 완료 메시지가 표시됩니다.

> 소리 알람이나 브라우저 푸시 알림은 제공하지 않습니다. 페이지를 닫거나 새로고침하면 진행 중인 타이머는 초기화됩니다.

### 5. 빠른 메모

아래쪽 **잠깐 떠오른 생각**에 자유롭게 입력하세요. 별도의 저장 버튼 없이 입력할 때마다 브라우저에 저장됩니다.

## 내 할 일과 메모는 어디에 저장되나요?

할 일과 메모, 마지막으로 불러온 날씨 지역은 **현재 브라우저의 로컬 저장소(`localStorage`)**에 저장됩니다.

- 할 일과 메모는 GitHub나 별도 서버로 전송되지 않습니다.
- 같은 기기·같은 브라우저·같은 사이트 주소로 다시 방문하면 저장한 내용을 볼 수 있습니다.
- 다른 기기나 다른 브라우저와 **자동 동기화되지 않습니다.**
- 웹사이트에서 입력한 내용과 다운로드한 HTML 파일에서 입력한 내용은 서로 공유되지 않습니다.
- 브라우저의 사이트 데이터를 삭제하면 저장한 내용도 삭제됩니다. 중요한 내용은 별도로 백업해 주세요.
- 시크릿 모드나 저장이 제한된 환경에서는 내용이 유지되지 않을 수 있습니다.

## 파일로 내려받아 사용하기

온라인 주소 대신 내 컴퓨터에서 열 수도 있습니다.

1. 이 저장소 위쪽의 **Code → Download ZIP**을 누릅니다.
2. 내려받은 ZIP 파일의 압축을 풉니다.
3. **`index.html`**을 더블클릭해 브라우저로 엽니다.

별도 설치나 빌드 작업은 필요 없습니다. 다운로드한 파일의 계산기와 타이머는 인터넷 없이도 작동하며, 날씨 조회에는 인터넷이 필요합니다. 파일로 열었을 때의 저장 동작은 브라우저 설정에 따라 달라질 수 있어, 꾸준히 사용할 때는 배포된 웹사이트를 권장합니다.

## 프로젝트 구조

```text
haru-weather/
├── index.html   # 앱 전체: 화면(HTML), 디자인(CSS), 기능(JavaScript)
├── README.md    # 지금 읽고 있는 소개 및 사용 설명서
└── .gitignore   # Git에 올리지 않을 파일 목록
```

앱은 **HTML 파일 하나**로 구성되어 있습니다. 별도 서버, 패키지 설치, API 키 설정 없이 실행할 수 있습니다.

## 코드를 수정하고 웹사이트에 반영하기

이 저장소는 **GitHub Pages**로 배포됩니다. GitHub Pages는 저장소의 HTML 파일을 웹사이트로 공개해 주는 기능입니다.

배포 기준은 **`main` 브랜치의 최상위 폴더(`/`)**입니다. 이 위치의 `index.html`이 웹사이트 첫 화면이 됩니다.

### 내 컴퓨터에서 수정하는 경우

이 프로젝트를 처음 설정한 컴퓨터에서는 **`haru-weather/index.html`**을 수정하세요. 상위 폴더의 원본 `하루정리.html`만 수정하면 배포 사이트에는 반영되지 않습니다.

PowerShell에서 프로젝트 폴더로 이동한 뒤 아래 명령어를 실행합니다.

```powershell
# 처음 설정한 컴퓨터의 프로젝트 폴더
cd "C:\Users\NHI\Desktop\얍\haru-weather"

# 1. 변경한 파일과 상태 확인
git status

# 2. 이번에 기록할 파일 선택
git add index.html

# 3. 변경 내용을 설명과 함께 기록 (커밋)
git commit -m "날씨 앱 화면 수정"

# 4. 기록한 변경 사항을 GitHub로 보내기 (푸시)
git push
```

README도 함께 수정했다면 `git add index.html README.md`로 두 파일을 선택하면 됩니다. README만 수정했다면 `git add README.md`를 사용하세요.

> **커밋**은 변경 내용을 내 컴퓨터의 Git 기록에 남기는 것이고, **푸시**는 그 기록을 GitHub에 올리는 것입니다. 푸시가 끝나면 GitHub Pages가 자동으로 다시 배포하며, 반영까지 보통 수 분 정도 걸립니다.

### GitHub 웹에서 간단히 수정하는 경우

1. 저장소에서 `index.html` 또는 `README.md`를 엽니다.
2. 연필 모양 **Edit this file**을 눌러 수정합니다.
3. **Commit changes**를 누르고 변경 내용을 설명한 뒤 `main` 브랜치에 커밋합니다.

이 방법은 GitHub에 바로 저장되므로 별도로 푸시할 필요가 없습니다. 이후 내 컴퓨터에서도 작업하려면 먼저 `git pull`로 원격 변경 사항을 받아오세요. 커밋하지 않은 로컬 수정이 있다면 먼저 정리한 뒤 실행하세요.

## 자주 묻는 질문

### 날씨가 표시되지 않아요.

인터넷 연결을 확인하고 날씨 카드의 새로고침을 눌러 주세요. 날씨 제공 서비스가 일시적으로 응답하지 않을 수도 있습니다.

### 휴대폰에서 PC에 적은 메모가 안 보여요.

정상 동작입니다. 데이터는 각 브라우저에 따로 저장되며 계정 기반 동기화 기능은 없습니다.

### 수정해서 푸시했는데 사이트가 그대로예요.

저장소의 [Actions 페이지](https://github.com/ilhabsida/haru-weather/actions)에서 `pages build and deployment`가 완료됐는지 확인하세요. 완료 후에도 이전 화면이면 브라우저를 새로고침하거나 `Ctrl + F5`로 강력 새로고침해 보세요.

### 다른 사람에게 공유해도 되나요?

아래 앱 주소를 보내면 상대방도 설치 없이 이용할 수 있습니다. 상대방에게 내 할 일이나 메모가 함께 전달되지는 않습니다.
